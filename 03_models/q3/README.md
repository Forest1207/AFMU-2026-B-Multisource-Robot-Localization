# 问题三：偏差检验驱动的异步融合

本目录实现附件 3 的完整可复现流程：

```text
4 Hz / 5 Hz 原始观测
  → 各自重置为相对经过时间后，用中心化位置相关给出粗时间偏差
  → 固定公共网格上的标准逐轴 Huber 剖面精配准
  → HAC-Wald 相对偏差检验 + 移动块 bootstrap + HAC 趋势检验
  → “统计显著且工程显著”双阈值选择是否启用偏差状态
  → 原始异步事件上的稳健 KF / RTS 平滑
  → 10 Hz 位置、速度、加速度及模型内位置标准差
```

## 关键约定

- 方式 2 的设备时刻映射到方式 1 参考时钟：`t2_corrected=t2-time_offset`。
- 估计的空间差始终是 `stream2-stream1` 的相对偏差；无外部真值时不能归因于某一设备。
- “未发现系统偏差”严格表示：在预设显著性水平与工程阈值下未拒绝零相对偏差，不表示数学上证明偏差恰为零。
- 偏差状态仅在 HAC-Wald 检验 `p<0.05` 且偏差模/稳健噪声尺度不小于 `0.25` 时启用；若同时检出趋势，再允许偏差随机游走。

## 正式结论

- 时间偏差约 `-367.88 s`；因 `t2_corrected=t2-time_offset`，方式 2 设备时钟比方式 1 参考时钟落后约 `367.88 s`，映射时其时间戳整体增加约 `367.88 s`（向后平移）。
- HAC-Wald `p=0.3511`，工程效应指数 `0.0681`；二维块 bootstrap 区间均覆盖 0，且未检出显著漂移。因此正式融合不启用系统偏差状态。
- 过程噪声调参阶段关闭门控反馈，用门控前 NIS 和 Cholesky 白化创新相关选得 `q=3.1623`；选定后才运行 99% 稳健门控。
- 正式 10 Hz 输出覆盖 `445.0076–814.0076 s`，共 3691 行。

## 文件

- `bias_test.py`：HAC 均值协方差、二维 Wald 检验、移动块 bootstrap 和 HAC 趋势检验。
- `robust_fusion.py`：不规则事件间隔 KF、NIS 稳健降权、RTS 平滑和状态协方差传播。
- `run_q3.py`：正式主入口。
- `test_synthetic.py`：已知时间偏差/系统偏差回收、100 随机种子的 HAC 检验经验尺寸/功效、块 bootstrap 覆盖和融合有限性检查。
- `run_sensitivity.py`：插值、Huber、搜索范围、HAC/块长、过程噪声和门控敏感性。
- `make_figures.py`：生成六组 PNG/SVG/PDF 图及来源清单。
- `validation.py`：正式产物机器门禁。

正式数据见 `05_results/q3`，图件见 `06_figures/q3`，论文段落见 `07_paper/q3.md`。
