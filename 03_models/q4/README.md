# 问题四：固定轨迹上的连续可行窗口与任务调度

本目录在问题三正式 10 Hz 轨迹上完成以下链路：

```text
轨迹状态 + 18个射击目标 + 18个拍照目标
  → 每个0.1 s执行时刻的完整准备窗检查
  → 连通窗、局部高裕度点与30°方向角箱候选压缩
  → PCHIP状态在0.01 s网格连续复核
  → 三阶段词典序MILP
  → 两位小数时刻再次0.01 s复核
  → 写入result.xlsx副本并核验未触碰区域
```

## 优化口径

题面没有明确任务准备是否可并行、同一射击目标能否重复计数。本文显式假设单机器人同一时段只能准备/执行一项任务，且每个射击目标至多计一次；这两条不是附件原文，正式论文已单独标注。

1. 在时间区间互斥、射击目标唯一、同一拍照目标角度差至少 60°等约束下，不设固定任务次数上限，最大化任务数。
2. 固定最大任务数后，最大化所有已选任务的最小归一化约束裕度。
3. 固定前两级最优值后，最大化总裕度，并以兼容拍照对的角度差作多样性奖励；射击命中率 0.85 只作小量同级择优和期望命中数报告，不改变硬约束。

最早完成贪心算法先给出 38 项可行下界，SciPy HiGHS MILP 随后得到 40 项最优解，各阶段均返回最优状态和 0 gap。第二、三级最优性针对经连续复核的压缩候选集。结果模板的预置行数不作为数学约束，导出时按实际任务数生成结果副本。

## 主要文件

- `trajectory_state.py`：读取并连续评估问题三固定轨迹。
- `shooting_model.py` / `photography_model.py`：题面约束、归一化裕度和方向角距离。
- `feasible_windows.py`：36 个目标的完整准备窗与 0.01 s 连续复核候选生成。
- `scheduler.py`：三阶段词典序 MILP。
- `run_q4.py`：正式主入口、贪心基线、扰动检验和模板保真写入。
- `make_figures.py` / `diagnostics.py`：四组正式图件。
- `validation.py`：约束、MILP、CSV、XLSX 和图件的机器门禁。
- `test_synthetic.py`：时间冲突、射击唯一性和拍照角度冲突的合成调度测试。

正式输出位于 `05_results/q4`；其中 `result.xlsx` 是可提交副本，原始模板从未修改。
