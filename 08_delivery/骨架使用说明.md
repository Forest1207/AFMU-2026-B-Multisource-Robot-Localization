# B题 LaTeX 项目使用说明

## 当前状态

项目为可编译的完整论文版本，包含四问模型、正式计算结果、正式图件、40 项任务结果表和参考文献，不设置附录。不含承诺书、编号专用页和目录，所有身份字段均为空；实际页数与 PDF 哈希以最近一次构建清单为准。

题目原文及射击、拍照约束完整保留在“问题重述—问题提出”中。题面未明示的“单机器人任务资源独占”和“同一射击目标至多计一次”在模型假设及问题四中明确标为建模约定。

## 编译方式

- 唯一入口：main.tex
- 引擎：XeLaTeX
- 文档类选项：withoutpreface,bwprint
- TeX Live：D:\texlive\2026\bin\windows
- 安全构建：不启用 shell escape
- Windows 注意：若用户名含中文，隔离编译前将 TEMP 与 TMP 指向纯 ASCII 路径，可避免 XeLaTeX 管道异常。

项目采用 A4 纸、四边25 mm页边距、正文小四宋体、两字符首行缩进、1.38倍行距；一级标题居中，二级标题左对齐，标题间距按用户提供的参考页收紧。页码从摘要页起在页脚居中连续编号。

## 关键文件

- contents/abstract.tex：答题型摘要及主要数字；
- contents/sections/s1.tex：问题重述、问题分析与四问关联；
- contents/sections/s2.tex：模型假设、建模约定与符号说明；
- contents/sections/s5.tex：唯一的第五章包装文件，生成5.1总体分析并依次载入四个模型；
- contents/sections/q1.tex 至 q4.tex：模型一至模型四，统一采用“建立—求解—算法—结果—检验”结构；
- contents/sections/s6.tex：跨模型误差传播、跨问接口、复现门禁、共同优点、总体局限与改进；
- figures/q1 至 figures/q4：已绑定权威来源的正式 PDF 图件；
- build/main.build.json：最近一次隔离构建记录。
- ../../04_experiments/reproduce_all_results.ipynb：从原始附件重算四问的可执行 Notebook。

## 结果与原始附件保护

原始赛题 PDF、附件1至附件4及原始 result.xlsx 始终只读。问题四不设置固定任务次数上限，正式结果为 40 项任务，其中射击 14 项、拍照 26 项；工作簿副本位于仓库 05_results/q4/result.xlsx。

当前论文 PDF 为 08_delivery/B题-完整论文.pdf。最终参赛提交时，按校赛通知将副本重命名为“B题+队号+队长姓名.pdf”；不要在电子版论文正文中加入队号、姓名、学校或指导教师。

## 提交前检查

1. 根据学校最终通知确认是否需要承诺书或编号页；当前电子版没有这两页。
2. 执行全流程 Notebook，确认 20 项复现门禁全部通过。
3. 使用 XeLaTeX 至少编译两轮，确认无未解析引用、重复标签、缺失文件和排版警告。
4. 检查摘要页、问题重述页、四个算法伪代码块、问题四结果表和参考文献页，确认无裁切或遮挡。
5. 保留原始附件哈希、参数 JSON、机器校验和 Notebook 执行输出，不用结果副本覆盖原文件。
