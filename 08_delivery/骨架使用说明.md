# B题 LaTeX 项目使用说明

## 当前状态

项目已由“可见占位骨架”更新为可编译的完整论文版本，包含四问模型、正式计算结果、15幅图、任务结果表、参考文献和附录。正文共25页，不含承诺书、编号专用页和目录；所有身份字段均为空。四问独立 P1 门禁均为 PASS。

题目原文及射击、拍照约束完整保留在“问题重述—问题提出”中。题面未明示的“单机器人任务资源独占”和“同一射击目标至多计一次”在模型假设及问题四中明确标为建模约定。

## 编译方式

- 唯一入口：main.tex
- 引擎：XeLaTeX
- 文档类选项：withoutpreface,bwprint
- TeX Live：D:\texlive\2026\bin\windows
- 安全构建：不启用 shell escape
- Windows 注意：若用户名含中文，隔离编译前将 TEMP 与 TMP 指向纯 ASCII 路径，可避免 XeLaTeX 管道异常。

项目采用 A4 纸、四边25 mm页边距、正文小四宋体、两字符首行缩进、1.38倍行距；一级标题居中，二级标题左对齐，标题间距按用户提供的参考页收紧。页码从摘要页起在页脚居中连续编号。

## 关键文件

- contents/abstract.tex：答题型摘要及主要数字；
- contents/sections/s1.tex：完整问题重述与问题分析；
- contents/sections/s2.tex：模型假设、建模约定与符号；
- contents/sections/s3.tex：数据审计、时间符号和统一框架；
- contents/sections/q1.tex 至 q4.tex：四问模型、结果与验证；
- contents/sections/s6.tex：综合稳健性、评价与改进；
- figures/q1 至 figures/q4：已绑定权威来源的正式 PDF 图件；
- contents/appendix/：结果索引、程序入口、轨迹样例和工作簿说明；
- build/main.build.json：最近一次隔离构建记录。

## 结果与原始附件保护

原始赛题 PDF、附件1至附件4及原始 result.xlsx 始终只读。问题四正式工作簿副本位于仓库 05_results/q4/result.xlsx，只修改 B2:E10；A列、H:L红色说明和范例及其他格式均经语义快照验证保持不变。

当前论文 PDF 为 08_delivery/B题-完整论文.pdf。最终参赛提交时，按校赛通知将副本重命名为“B题+队号+队长姓名.pdf”；不要在电子版论文正文中加入队号、姓名、学校或指导教师。

## 提交前检查

1. 根据学校最终通知确认是否需要承诺书或编号页；当前电子版没有这两页。
2. 核对四问 CSV、参数 JSON、论文数字和 result.xlsx 九行完全一致。
3. 使用 XeLaTeX 至少编译两轮，确认无未解析引用、重复标签、缺失文件和排版警告。
4. 检查摘要页、问题重述页、图表页、问题四结果表和附录页，确认无裁切或遮挡。
5. 保留原始附件哈希和四个 P1 门禁证据，不用交付副本覆盖原文件。
