# 参考提交包迁移记录

## 背景

本分支以用户提供的“参赛提交版”参考包作为工程与问题四建模参考，但不直接覆盖当前仓库已经完成验证的 Q1--Q3 正式模型。

参考包最值得迁移的能力包括：

1. LaTeX 论文工程；
2. 正式图件与 TeX 表格自动引用；
3. 数据/结果/约束审计；
4. 一键主流程；
5. 最终交付打包与文件清单；
6. Q4 的“目标覆盖 + 多角度拍照”MILP 结构；
7. Q4 的 5° 拍照方位角候选压缩与 MILP 后连续时间局部精修。

## Q1--Q3 决策

保留当前仓库模型：

- Q1：互相关粗定位 + 固定位置 MSE 连续精配准 + 10 Hz 重建；
- Q2：Huber 时空标定 + 原始异步事件 KF + RTS；
- Q3：HAC--Wald + moving-block bootstrap + 工程效应阈值 + 稳健 KF/RTS。

原因是当前模型在统计假设、异步融合、敏感性分析和合成验证方面已经形成更完整证据链。

## Q4 关键纠正

### 错误 1：把模板 9 个初始结果行视作容量

题目没有给出最多 9 项任务的限制。参考包会在 A:E 继续向下写入全部任务，因此新版正式模型删除

```text
sum(x) <= 9
```

约束。

### 错误 2：把准备窗口重叠视作任务资源冲突

题目只规定射击/拍照前的运动状态和准备时长，没有说明不同任务准备过程互斥。参考包没有跨任务时间冲突约束，因此新版正式模型同样删除这一人为限制。

## 参考包 Q4 MILP 结构

参考包采用：

1. 候选任务变量 `x`；
2. `(任务类型, 目标编号)` 覆盖变量 `y`；
3. `y` 与候选 `x` 的链接约束；
4. 同一射击目标最多一次；
5. 同一拍照目标方位角不足 60° 的候选对不能同时选择；
6. Stage 1 最大化目标覆盖数；
7. Stage 2 固定覆盖数后最大化拍照数；
8. Stage 3 固定前两级后最大化质量/安全裕度。

本仓库 `03_models/q4/scheduler.py` 已采用该结构。

## 候选压缩与连续精修迁移

进一步吸收参考包中两个重要实现细节：

- 拍照候选按 **5° 方位角箱**保留每箱最高安全裕度候选，并补充连续可行段端点；
- MILP 组合确定后，对每个任务在原执行时刻附近 **±0.1 s** 内做有界连续搜索。

本仓库在此基础上增加更严格的验证：

- 所有压缩候选先以 0.01 s 网格复核整个准备窗口；
- 连续精修后的拍照任务必须继续满足同一目标照片间至少 60°；
- 最终执行时刻保留两位小数后再次以 0.01 s 复核完整准备窗口和组合约束。

## 参考包复现问题及修复

参考包的主入口依赖未随压缩包提供的 `DATA_FACTS.json` / `DATA_PROFILE.json`，导致“解压后直接运行主程序”并不完全自洽。

本仓库不复制该隐藏依赖，而改用版本控制中的 `input_manifest.json` 明确声明输入契约；正式主流程只依赖官方附件和仓库内代码。
