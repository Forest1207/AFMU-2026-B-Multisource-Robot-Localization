# Decisions

记录关键模型选择及其理由。

## 2026-08-19 — Q1 正式模型

- 选择“异频速度互相关候选 + 全局位置 MSE 扫描 + 固定评价网格连续优化”，而不把互相关峰直接作为答案；原因是附件 1 轨迹近似周期，最高互相关峰位于错误周期。
- 选择 Cubic Spline 重建无噪声轨迹；四种插值对比中其跨传感器对齐 RMSE 最低，且满足连续可导需求。
- 时间偏差统一定义为 `t2_aligned = t2 + Δt`，Q1 正式报告 `Δt=-198.4317 s`。
- 10 Hz 输出采用两设备对齐后观测支持区间的并集，不在首尾进行无数据外推。
- Python 作为数据求解与数据图语言：仓库已有完整 NumPy/SciPy/Pandas 实现、依赖可复现，且无需 MATLAB 专有工具箱；非数据流程图后续仍按项目规范使用 MATLAB 绘制。
