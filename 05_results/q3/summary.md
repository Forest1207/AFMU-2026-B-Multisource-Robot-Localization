# 问题三正式结果摘要

## 偏差判定

- 时间偏差采用 `t2_corrected=t2-time_offset` 约定，正式值为 **-367.88 s**（机器值 -367.877619 s）；即方式 2 设备时钟比方式 1 参考时钟落后约 367.88 s，映射时其时间戳整体增加约 367.88 s（向后平移）。
- 固定公共网格的标准 Huber 剖面位置差约为 `(-0.152,-0.150) m`。用于推断的普通均值为 `(-0.134,-0.157) m`，其模长为 **0.206 m**。
- HAC-Wald 检验统计量为 **2.094**，`p=0.3511`，在 5% 水平不拒绝“零相对系统偏差”。偏差模与稳健噪声尺度之比仅 **0.0681**，低于预设工程阈值 0.25。
- 2000 次移动块 bootstrap 的 95% 区间为：x 轴 `[-0.413,0.138] m`，y 轴 `[-0.428,0.120] m`，均覆盖 0。
- HAC 趋势检验 x/y 斜率 p 值为 **0.378/0.921**，未检出漂移。故正式融合不启用常量或漂移系统偏差状态。

上述结论是“当前样本与阈值下未发现具有统计和工程意义的相对系统偏差”，不是证明真实偏差严格等于零，也不能把相对差归因于某一设备。

## 融合与验证

- 两设备三阶差分稳健测量协方差分别约为 `diag(16.06,18.21)` 与 `diag(7.24,8.94) m²`。
- 调参阶段关闭协方差膨胀，用门控前 NIS 与 Cholesky 白化创新 lag-1 选择 `q=3.1623`；选定后运行 99% 稳健门控。
- 门控前平均 NIS 为 **2.0127**，95% 分位为 **5.9590**；门控后平均 NIS 为 **1.9957**；白化创新平均绝对 lag-1 为 **0.0274**；约 **1.033%** 观测被降权。
- 10 Hz 轨迹覆盖 **445.0076–814.0076 s**，共 **3691** 行；状态全有限，位置模型内合成标准差中位数约 **0.961 m**、最大值约 **3.459 m**。
- 插值/Huber/搜索范围对照的时间偏差范围为 `[-367.9614,-367.8715] s`；三组 HAC/块长组合均不拒绝零偏差。将 q 乘 0.1/10 后轨迹 RMS 变化为 0.391/0.456 m；门控概率改为 0.975/0.995 时变化为 0.0391/0.0195 m，核心偏差判定不变。
- 合成试验回收真时间偏差 `0.18 s` 为 `0.1785 s`，回收真空间偏差 `(0.60,-0.35) m` 为 `(0.599,-0.355) m`。100 个 AR(1) 随机种子下，零偏差经验拒绝率为 0.08、偏差 `(0.03,-0.03) m` 的检验功效为 1.00；30 个种子的块 bootstrap 双轴联合覆盖率为 0.867。
- 10 Hz 非事件时刻及协方差是从前一 RTS 平滑事件节点作最大不足 0.208 s 的模型传播近似；偏差区间也是条件于正式时间配准值的条件推断。二者均未被表述为严格连续时间平滑或同时覆盖配准不确定性的联合区间。

正式数值以 `parameters.json`、`trajectory_10hz.csv`、`sensitivity.csv` 和 `validation.json` 为准。
