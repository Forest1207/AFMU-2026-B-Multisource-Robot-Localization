# 数模论文分问精修

把用户指定的分问整理成“模型推导清楚、结果集中完整、图表信息不重复、语言不暴露写作过程”的论文正文。先理解该分问自身的模型与数据，再复用版式和编辑标准；不得把前一问的算法、变量、数值或结论机械移植到后一问。

## 开始前

1. 定位主 LaTeX 入口、目标分问源码、图片目录、当前 PDF，以及用户指定的另一版本论文或 LaTeX 体系。
2. 读取目标分问全文和所有交叉引用，检查摘要、问题分析、综合评价、附录中是否存在同步表述。
3. 列出目标分问当前的章节结构、公式标签、图表标签和计算结果。若需要跨版本选图，必须读取另一版本正文中的真实 `\includegraphics` 引用，不按文件名猜测。
4. 保留用户已有修改，不覆盖无关章节，不删除用户文件。替换正式 PDF 前创建时间戳备份。

## 内容边界

### 模型建立与求解

- 只写变量、假设、观测关系、目标函数、约束、估计量和算法推导。
- 不写由本组数据计算得到的偏差值、最优点、RMSE、样本数、搜索区间数值、候选数量或图表结论。
- 题目直接规定的常数可以保留，例如输出频率、物理阈值和单位；将算法实现参数优先写成符号，在结果分析中给出实际取值。
- 若数据来自连续真实过程的采样，优先用观测方程表达，而不是用“可以视作”等解释性句式。例如：

```latex
\mathbf p_i^{(m)}=\mathbf r^\star(t_i^{(m)}+\delta_m)+\boldsymbol\varepsilon_i^{(m)}.
```

- 是否保留噪声项、系统偏差项和协方差结构由目标分问决定。问题二、三通常不能照搬问题一的无噪声观测式。
- 删除不服务于最终模型的候选方法罗列、插值函数选型实验和比较图表。若模型选择本身是结论的一部分，则保留必要判据，但不要把选型试验混入公式推导。
- 伪代码使用数学算法形式，输入为数据与符号参数，输出为估计量和轨迹；不得在伪代码中写本次运行的具体最优值、行数或固定起止时刻。

### 结果分析

- 集中给出主求解链中实际使用的所有中间结果：可行域、粗估值、精修区间、参数取值、最终估计、公共区间、误差、合并数量和输出规模。只保留与该分问真实算法相符的项目。
- 按“参数结果 -> 核心估计 -> 校正或融合效果 -> 输出轨迹”的顺序陈述。
- 先写数值及其含义，再放对应图；每幅图紧跟支撑它的文字，不把所有图前说明集中在一页、图片堆到后页。
- 结果只解释图中可见的信息，不写“该图进一步证明”“形成相互印证”“从工作流可见”等泛化判断。
- 图中使用舍入参数而正文使用未舍入参数时，明确说明两种数值口径以及误差差异，不能留下图文冲突。

### 检验小节

- 当用户要求采用本次问题一的同款结构时，删除独立的“模型检验与稳健性”小节及其内容，包括合成恢复、参数敏感性、边界伪最优和适用边界等论述。
- 不得把被删除的小节改名后整体塞入“结果分析”。只有主求解流程必需的结果或用户明确要求的对比指标可以保留。
- 同步删除摘要、问题分析、综合评价和交叉引用中对该检验小节的承诺或引用。
- 若问题三的统计检验本身就是题目任务或核心模型结论，它不属于可删除的附加稳健性小节，必须保留在模型或结果中。

## 语言清理

把暴露写作过程、代理思考或交付流程的文字改成客观论文陈述。

优先改写：

- “正式报告为” -> “按输入精度取”或直接陈述数值；
- “采用符号约定” -> 直接定义符号；
- “连续优化得到原始估计” -> “连续优化值为”；
- “本文选择”“需要说明的是”“最终采用” -> 直接写判据和结论；
- “上述各计算阶段”“工作流程”“形成相互印证” -> 写明具体变量、数值关系或图中现象。

不要机械删除正常的数学连接词。保留“由式可得”“因此”“其中”等真正承担推导关系的词。

## 跨版本图表

1. 读取两个版本实际使用的图，并渲染查看图内标题、图例、单位、数值和时间范围。
2. 按表达内涵分组，例如目标函数、校正效果、融合结果、输出轨迹。
3. 同组图片只保留一幅：优先选择信息维度更完整、标注更清楚、视觉质量更高且与当前正文数值一致的版本。
4. 只有表达不同证据维度时才同时保留，例如全域目标函数与局部联合目标图。用户要求删除重复内涵时，宁可少图，不以“角度不同”为由保留低信息图片。
5. 默认不引入流程图、装饰图、单纯重复正文的表格；用户明确要求时除外。
6. 复制引入的 PDF 图片到项目权威资源目录和 LaTeX 图片目录，保持原文件哈希一致。源码只引用最终入选图片。
7. 删除舍弃图表的环境、引出文字、分析文字、标签引用和跨章节引用。未引用资源可以保留在磁盘，但不得进入论文。

## LaTeX 排版

- 图表编号交给 LaTeX 自动生成，不手工写“图 1”“表 2”。
- 图题说明图展示的对象，不在题注中写结论性长句。
- 控制图片宽度，使坐标、图例和中文标注可读。相邻图片若能在同页清晰呈现，可以连续排版；否则一图一页。
- 必要时在图后使用 `\clearpage` 清空浮动队列，保证下一段分析不会跑到对应图片之前，并保证本问图片不漂移到下一问。
- 删除图表后检查公式、图、表编号以及所有 `\ref`、`\eqref` 和章节引用。

## 编译与交付

1. 使用项目指定的 LaTeX 引擎连续编译至少两遍。
2. 阻断未解析引用、重复标签、Overfull/Underfull box、字体警告和编译错误；修复后重新编译。
3. 将目标分问起止页渲染为图片，逐页检查：
   - 分问标题与上一页衔接正常；
   - 模型建立与求解中没有具体运行结果；
   - 结果文字与对应图片顺序一致；
   - 无重复图、空白页、图文冲突或图片漂移；
   - 下一分问从正确位置开始。
4. 搜索已删除标题、标签、AI 过程词和旧图表名，确认没有残留。
5. 备份现有正式 PDF，再同时替换项目 `main.pdf` 和用户指定的正式 PDF。比较候选文件与两个目标文件的 SHA-256，必须完全一致。
6. 最终说明修改范围、保留和删除的图表、编译状态、PDF 路径与备份路径；不要声称未实际执行的校验。
